# Stakeholder Profiles

## Management

- Name / Role: ผู้บริหาร
- Team: management
- Data Literacy Level: high
- Critical Questions:
  - ความเสี่ยงที่ยังไม่ปิดกระจุกอยู่ที่หน่วยงานใด
  - ควรติดตามรายการความเสี่ยงใดก่อน
- Current Pain Points:
  - ต้องอ่านข้อมูลจากไฟล์ Excel และจัดอันดับความเสี่ยงด้วยมือ
- Preferred Format:
  - dashboard
- Decision Cadence:
  - ทุกครั้งที่มีการ update ข้อมูล
